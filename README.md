# Week 1 — Data Foundations & First Exploration

This repository contains all three analytical tasks completed for the **Week 1: Data Foundations** module. The projects cover data loading, quality verification, exploratory data analysis (EDA), and multi-dimensional analytics using Python's data analysis stack (`pandas`, `matplotlib`, `seaborn`).
